# Security and disclosure policy

This repository is intended for public, reusable workflows.

Do not submit:

- Credentials, tokens, cookies, session identifiers, or private keys.
- Internal domains, endpoints, repository names, hostnames, or absolute workstation paths.
- Company source code, documents, prompts, datasets, business metrics, customer data, or organization details without explicit authorization.
- Examples that require bypassing authentication, security controls, licenses, or platform restrictions.

Use synthetic examples and redact identifying metadata. If sensitive content is discovered, stop distribution, remove the exposed material from the current version, rotate affected credentials, and follow the relevant organization's incident process. Deleting a Git commit alone does not invalidate an exposed secret.

Research performed by these skills treats third-party repositories as untrusted. Read-only inspection does not authorize dependency installation or code execution.
